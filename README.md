## Run Projects
📁 Step 1 — Install the Required Tools
You need two things installed on your computer first. Do these once ever:
A) Install Node.js (this is what makes npm work)

Go to nodejs.org and download the LTS version (the big green button)
Run the installer, click Next through everything
To verify it worked, open your Terminal (Mac) or Command Prompt (Windows) and type:

node --version

It should print something like v20.x.x ✅
B) Install Git (this is what lets you download from GitHub)

Go to git-scm.com and download for your OS
Run the installer, click Next through everything
To verify: in your terminal type:

git --version

It should print something like git version 2.x.x ✅

📁 Step 2 — Clone (Download) the Repository
"Cloning" just means downloading a live copy of the code to your computer. In your terminal:
git clone https://github.com/BridgeVoice/bridgevoice-frontend.git
This creates a folder called bridgevoice-frontend on your computer wherever your terminal is currently pointed.

📂 Step 3 — Navigate Into the Folder
cd bridgevoice-frontend
cd means "change directory" — you're just stepping inside the folder.

📦 Step 4 — npm install
npm install
This reads the package.json (the ingredients list) and downloads all the libraries the project needs. It creates a folder called node_modules. This takes 1–2 minutes. You only do this once (or when new packages are added).

🚀 Step 5 — npm run dev
npm run dev
This starts the app on your computer. You'll see something like:
  VITE v5.x.x  ready in 300ms

  ➜  Local:   http://localhost:5173/
Open that link in your browser — you're now running BridgeVoice on your own machine! 🎉

🔁 Going Forward
Every time you want to work on the project after the first setup, you only need Steps 3 + 5:
cd bridgevoice-frontend
npm run dev
That's it!
